# 安全与合规

封页台是**离线归档格式与完整性核验**的教学/评测工具。使用本工具即表示你只在自有或明确授权的本地环境中运行，并遵守所在地法律与组织政策。

## 回环目标白名单

- 唯一允许的主机集合：`127.0.0.1`、`localhost`、`::1`。
- 校验发生在**建立连接之前**：种子解析、每一跳 redirect、外链过滤、`serve-site`/`replay` 绑定地址均独立校验。
- 非回环目标立即拒绝，不发起 DNS 后的网络请求；该事件以稳定原因写入 `ledger.sqlite3` 的 `rejected_targets` 表，并在报告 `crawl.rejected_targets` 中计数。
- 不存在“关闭白名单”“允许公网”“代理出口”的配置项或隐藏开关。修改代码绕过白名单不属于受支持用法。

实现位置与留痕：`src/pagefreeze/policy.py` 的 `ALLOWED_HOSTS`、`is_loopback_target`、`ensure_allowed_url`、`validate_bind_host` 提供白名单判定；`fetch.py` 在打开连接前再次调用；`crawl.py` 将拒绝事件放入 `RejectedTarget`，`pipeline.py` 经 `ledger.write_run` 写入 `rejected_targets` 表并同步报告计数。静态资源发现的外链（如 `link rel=stylesheet` 指向公网）在入队前经过同一 `is_loopback_target` 检查，并以 `kind`/`raw_reference` 标明引用类型与原始 token。

## 合成数据声明

仓库内的站点、页面、URL、域名、IP、公司名、产品名、人名、日志、样式与图像全部是为演示构造的本地合成数据。示例中的 `127.0.0.1` 是回环地址，`203.0.113.7` 是文档保留地址且仅作为**被拒绝的外部链接**出现，不对应真实服务。任何与真实组织或个人的相似均属巧合。

不包含真实凭证、密钥、令牌、Cookie、身份证号、手机号、邮箱或任何个人数据。需要占位的敏感字段统一写为 `REDACTED_DEMO_VALUE`；测试夹具不得加入形如真实 token 的字符串。

## 明确禁止的行为

本工具不实现、不协助、也不提供配置入口用于：

- 登录爆破、口令猜测、会话固定或任何认证绕过；
- Cookie 窃取、凭证收集、浏览器存储提取；
- UA 池伪造、指纹伪装、代理轮换；
- 限流绕过、robots 规避、封禁规避或检测规避；
- 对非授权目标的大规模抓取、压力测试或拒绝服务；
- 抓取、存储或传播真实个人信息、商业秘密或受访问控制保护的内容。

内置的请求间隔、超时、页数上限、MIME 白名单与 robots 支持是约束，不是可绕过的建议值。

## 请求与数据最小化

- 请求记录仅保留方法、Host、固定 UA、Accept、Connection；**不记录** Cookie、Authorization、Set-Cookie 或其他凭据头。
- 不执行 JavaScript、不抓取 `<script src>`、不加载归档页面中的外部资源；CSS 只做文本级引用解析，不解释或执行任何样式逻辑。
- 静态资源发现受 `resource_depth`、`max_pages`、robots 与回环白名单共同约束：`resource_depth=0` 完全关闭，未知格式或超限引用只留痕不抓取。
- 回放首页为本地生成的纯 HTML，无脚本、无外部图片或字体。
- 响应体超过配置上限即拒绝读取并放弃归档；不将超限内容写入磁盘。
- 不回传任何数据到外部服务；工具没有遥测、更新检查或外发通道。

## 日志与产物卫生

- 报告与索引使用相对文件名，不写绝对路径、用户名、主机名或系统时间。
- 台账只记录运行所需的 URL、状态、摘要、偏移与拒绝原因。
- `runtime/`、SQLite 台账、测试缓存均在 `.gitignore` 中；发布归档前应确认其中不含环境特有信息。
- 错误消息只描述本地文件/字段问题，不回显响应体或凭据。

## 运行边界

- 应用运行时仅依赖 Python 3.10+ 标准库；`pytest` 仅用于开发测试。
- 自动化测试全部使用回环 mock 站点，不访问外部网络。
- 回放服务默认只绑定 `127.0.0.1:18081`，mock 站点默认只绑定 `127.0.0.1:18080`；绑定非回环地址会被拒绝。
- 本项目按“现状”提供，不附带任何对特定用途、合法性或适销性的担保；使用者对运行环境与授权负责。

如发现安全问题，请在本地记录复现步骤与受影响文件，不要对真实第三方目标进行验证。
